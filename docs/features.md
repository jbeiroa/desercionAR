# ETL Pipeline Feature Map

This document outlines the features generated by the ETL pipeline located in `src/pipelines/etl.py`. The final dataset is designed for predicting student dropout.

**Note:** This list was inferred from the logic in the main pipeline script, as some underlying feature definition files could not be accessed directly. The descriptions are based on official INDEC EPH documentation.

---

## Detailed Step-by-Step Analysis

### Step 1: `extract()` - Initial Data Ingestion

The pipeline starts by reading `individual` and `hogar` EPH datasets.

- **Method**: `_select_and_join_features`
- **Description**: This step selects a predefined set of columns from the raw EPH data and joins the individual and household tables.
- **Total Columns after step**: **74**
- **Full Column List**:
  - **IDs & Metadata**: `CODUSU`, `NRO_HOGAR`, `COMPONENTE`, `H15`, `ANO4`, `TRIMESTRE`, `REGION`, `MAS_500`, `AGLOMERADO`, `PONDERA`, `REALIZADA`
  - **Individual Features**: `CH03`, `CH04`, `CH06`, `CH07`, `CH08`, `CH09`, `CH10`, `CH11`, `CH15`, `CH16`, `ESTADO`, `CAT_OCUP`, `CAT_INAC`, `PP02E`, `PP02H`, `PP07I`, `PP07H`, `PP04B1`, `T_VI`, `NIVEL_ED`, `V2_M`
  - **Household Features**: `IV1`, `IV2`, `IV3`, `IV4`, `IV5`, `IV6`, `IV7`, `IV8`, `IV9`, `IV10`, `IV11`, `IV12_1`, `IV12_2`, `IV12_3`, `II1`, `II2`, `II3`, `II4_1`, `II4_2`, `II4_3`, `II7`, `II8`, `II9`, `V1`, `V2`, `V21`, `V22`, `V3`, `V5`, `V6`, `V7`, `V8`, `V11`, `V12`, `V13`, `V14`, `IX_TOT`, `IX_MEN10`, `IX_MAYEQ10`, `ITF`, `DECCFR`

### Step 2: `transform()` - Feature Engineering

This step enriches the dataset with new features related to household structure and socio-economic indicators (NBI - *Necesidades Básicas Insatisfechas*).

- **Method**: `_apply_transformations`
- **Description**: Applies a series of transformation functions defined in `src/features/build_features.py`.
- **Columns Added (+25)**:
  - **Household Structure**: `CH04_jefx`, `CH06_jefx`, `ESTADO_jefx`, `NIVEL_ED_jefx`, `PP02E_jefx`, `CAT_OCUP_jefx`, `PP07I_jefx`, `PP07H_jefx`, `PP04B1_jefx`, `CH04_conyuge`, `ESTADO_conyuge`
  - **Employment Status**: `JEFE_TRABAJA`, `CONYUGE_TRABAJA`
  - **Household Demographics**: `JEFA_MUJER`, `HOGAR_MONOP`, `ratio_ocupados`
  - **NBI Features**: `NBI_VIVIENDA`, `NBI_HACINamiento`, `NBI_TENENCIA`, `NBI_SANITARIA`, `NBI_ZONA_VULNERABLE`, `NBI_DIFLABORAL`, `NBI_TRABAJO_PRECARIO`, `NBI_SUBSISTENCIA`, `NBI_COBERTURA_PREVISIONAL`
- **Total Columns after step**: **99**

### Step 3: `load()` - Final Processing and Output

This final stage prepares the data for modeling. It involves creating the target variable, cleaning the data, handling duplicates, and splitting it into train, test, and prediction sets.

#### Sub-step 3.1: Target Generation (`_generate_dropout_target`)
- **Columns Added**: `DESERTO`, `CH10_fin`
- **Columns Removed**:
  - **`CH10_fin`**: This column is sourced from the subsequent quarter's data to determine if a student is still enrolled. It is used to create the `DESERTO` target variable and then immediately dropped.

#### Sub-step 3.2: Preprocessing (`_preprocess_data`)
- **Columns Renamed**:
  - `PP04B1` -> `servicio_domestico`
  - `PP07H_jefx` -> `APORTES_JUBILATORIOS_jefx`
- **Temporary Columns Created and Dropped**:
  - `x_temp`, `y_temp`, `distance`: These are created within the `_distance_to_capital` method to calculate the distance of each `AGLOMERADO` to the capital and are dropped after the calculation.
- **Columns Permanently Dropped (-21)**:
  - The following columns are explicitly removed from the dataset.

#### Sub-step 3.3: Deduplication (`_remove_duplicates`)
- **Temporary Columns Created and Dropped**:
  - `_merge`: This column is created by a `pandas.merge` operation to identify and remove duplicate records between the train, test, and predict sets. It is dropped immediately after the filtering is complete.

- **`CAT_OCUP_jefx`**: Created in `join_heads_spouses`.
